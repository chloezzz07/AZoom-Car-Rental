# AZoom-Car-Rental
Project Overview
AZoom Car Rental is a frontend web application. The website allows customers to reserve, collect, and return rental cars. Employees can inspect returned vehicles, and customers can confirm their final rental payment.
Features
Customer Portal
1.Browse available rental cars with images and daily rental prices.
2.Reserve a car by selecting rental dates and entering simulated credit card details.
3.Confirm vehicle pickup at the AZoom office.
4.Return the vehicle to a designated car park.
5.View the final bill after employee inspection.
6.Confirm final payment.
7.Start a new rental by clearing the current rental record.

Employee Portal
1.View customer booking details.
2.Check vehicle pickup and return status.
3.Inspect a returned vehicle.
4.Record the vehicle condition and any damage charges.
5.Update the final rental bill.

How to Use
Open the live website.
Select the Customer Portal.
Complete the booking, pickup, and return steps.
Open the Employee Portal in another tab of the same browser.
Complete the vehicle inspection.

Return to the Customer Portal to view and confirm the final payment.
